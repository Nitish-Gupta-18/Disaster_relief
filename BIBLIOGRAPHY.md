### Notes on IEEE style used above

- **Author**: individual name as `A. B. Surname`, or the organization when no individual is named.
- **Title**: quoted for articles/web pages, *italicized* for books and major works.
- **Date**: publication or version year; use the year you accessed the resource if no date is published.
- **URL**: every web reference must end with an accessible link; `[Online]` marks non-print sources.
- **Order**: number references in the order they first appear in your report body, not alphabetically.

> Add any textbooks, journal papers, or domain resources (e.g., NDMA/FEMA disaster-management publications) you consulted while writing the report to this list, and renumber all entries so citations remain in first-appearance order.
